# Deep Learning Files from Research at the JHU SOM

## DL Prediction Evaluation Script 1
This file allows you to evaluate how good your predictions are for one prediction TIFF file against one mask TIFF file.

## Eval Script Looped 1
This file allows you to evaluate how good your predictions are for an entire folder of prediction TIFF files against an entire folder of mask TIFF files.

## Viewing TIFF Files Script 1
This file simply allows you to view TIFF files.
